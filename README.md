# Trabajo para el segundo cuatrimestre de DIW con las nuevas especificaciones:
Tomando como punto de partida el proyecto de la primera evaluación se requiere realizar las siguientes tareas: 
1) Se deberá modificar la página principal para que incluya alguna animación, la que considere más oportunas.
2) Se deberá modificar el formulario de contacto de forma que contenga los campos: nombre, apellidos, dirección, localidad, provincia, fecha de nacimiento, dirección de email, campo observaciones y un campo donde se acepten las políticas de privacidad. El formulario se deberá validar y no se podrá enviar si algún campo no es válido o no está cumplimentado. Se informará al usuario del motivo de error para cada campo. Se recomienda usar datepicker para la fecha de nacimiento.
3) Se deberá añadir otra página web a la aplicación o donde se considere para comprar productos/entradas/servicios dependiendo del proyecto que se ha realizado. De forma que se presente en la página un carrito con el contenido seleccionado. No es necesario que se ejecute finalmente la compra. Se puede utilizar JQuery, JavaScript.
4) Se deberá implementar el portal atendiendo a los principios de usabilidad visto y estudiados en la unidad de trabajo 5. Una buena opción es revisar el portal siguiendo el checklist utilizado en la dicha unidad de trabajo.
5) El portal se deberá implementar atendiendo a los parámetros de accesibilidad vistos y estudiados en la unidad de trabajo 6.
6) Deberá estar desplegado en un alojamiento público desde el que se pueda visualizar(el mismo que en la primera tarea).
7) En la tarea habilitada en el Aula Virtual habilitada para ello sólo se deberá subir un documento de texto con la url del proyecto.
